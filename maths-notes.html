Chapter 1 — Orienting Yourself: The Use of Coordinates

Concept notes

Key ideas

  • A coordinate system describes the position of a point using ordered numbers.
  • The Cartesian plane has a horizontal x-axis and a vertical y-axis.
  • Their intersection is the origin, written (0, 0).
  • A point is written (x, y): move x units horizontally, then y units vertically.
  • Positive x is to the right; negative x is to the left. Positive y is upward; negative y is downward.
  • The axes divide the plane into four quadrants. Points on an axis are not inside any quadrant.

Remember

In (−3, 2), the first number tells horizontal movement and the second tells vertical movement. Do not reverse the order.

Important questions with answers

1. What is the origin?
The point where the x-axis and y-axis intersect. Its coordinates are (0, 0).
2. What does an ordered pair (a, b) represent?
It represents a point whose horizontal coordinate is a and vertical coordinate is b.
3. In which quadrant does (−4, 5) lie?
Second quadrant: x is negative and y is positive.
4. Can a point on the x-axis belong to a quadrant?
No. Points on either axis are boundary points and do not belong to any quadrant.

Worked examples

Example 1: Locate (3, −2). Start at the origin, move 3 units right, then 2 units down. It lies in the fourth quadrant.

Example 2: Identify the coordinates of a point 4 units left and 1 unit up from the origin. Answer: (−4, 1).

Practice exercises

  1. Write the coordinates of the origin.
  2. Name the quadrant containing (−2, −7).
  3. Which axis contains (0, 6)?
  4. Describe how to plot (5, 3).
  5. State whether (−3, 0) lies in a quadrant.

MCQ

  1. The point (2, −5) lies in: (A) I (B) II (C) III (D) IV
  2. The y-coordinate of (−6, 4) is: (A) −6 (B) 4 (C) 6 (D) −4

Answer key

1. (0,0); 2. Third quadrant; 3. y-axis; 4. 5 right, 3 up; 5. No, it lies on x-axis. MCQ: 1-D, 2-B.

Long-answer / exam-style

Explain how to plot (−3, −4) on a Cartesian plane.
Begin at (0,0). Move 3 units left because x = −3. From there move 4 units down because y = −4. Mark the point and label it (−3,−4). Since both coordinates are negative, it lies in the third quadrant.

Chapter 2 — Introduction to Linear Polynomials

Key ideas

  • A polynomial in one variable is an expression made from constants and non-negative integer powers of the variable, combined using addition, subtraction and multiplication.
  • A term has a coefficient and a variable part. In 5x, the coefficient is 5.
  • A linear polynomial in x has degree 1 and can be written ax + b, where a is not zero.
  • The degree is the greatest exponent of the variable with a non-zero coefficient.
  • To evaluate a polynomial, substitute the given value for the variable and simplify carefully.
  • A zero of a polynomial is a value of the variable that makes the polynomial equal to zero.

Important questions with answers

1. What is a linear polynomial?
A polynomial of degree 1, such as 3x + 2.
2. What is the degree of 7x − 9?
1, because the highest power of x is 1.
3. Evaluate 2x + 5 when x = 3.
2(3) + 5 = 11.
4. Find the zero of x − 6.
Set x − 6 = 0, so x = 6.

Worked examples

Example 1: Evaluate 4x − 3 at x = −2: 4(−2) − 3 = −8 − 3 = −11.

Example 2: Find the zero of 3x + 12: 3x + 12 = 0 ⇒ 3x = −12 ⇒ x = −4.

Practice

  1. State the degree of 9x + 1.
  2. Evaluate 5x − 2 for x = 4.
  3. Find the zero of x + 8.
  4. Is 4x² + 1 a linear polynomial? Explain.

Answers: 1; 18; −8; No, its degree is 2.

MCQ

The degree of 6x − 11 is (A) 0 (B) 1 (C) 2 (D) 6. Answer: B.

Long-answer / exam-style

Find the zero of 5x − 20 and verify it.
Set 5x − 20 = 0. Then 5x = 20, so x = 4. Verification: 5(4) − 20 = 20 − 20 = 0. Hence 4 is the zero.

Chapter 3 — The World of Numbers

Key ideas

  • Natural numbers are counting numbers: 1, 2, 3, … .
  • Whole numbers include 0 and the natural numbers.
  • Integers include positive numbers, negative numbers and zero.
  • Rational numbers can be written as p/q, where p and q are integers and q is not zero.
  • Terminating decimals and repeating decimals are rational numbers.
  • Real numbers include rational and irrational numbers.
  • An irrational number cannot be expressed as a ratio of two integers; its decimal expansion is non-terminating and non-repeating.

Important questions with answers

1. Is every integer rational?
Yes. Any integer n can be written as n/1.
2. Give an example of an irrational number.
√2 is irrational.
3. Is 0.75 rational?
Yes. 0.75 = 75/100 = 3/4.
4. What are real numbers?
The collection of all rational and irrational numbers.

Worked examples

Example 1: Convert 0.625 to a fraction: 0.625 = 625/1000 = 5/8.

Example 2: Classify −7: it is an integer, rational (−7/1), and real.

Practice

  1. Write 0.4 as a fraction in simplest form.
  2. Is √9 irrational? Explain.
  3. Give one integer that is not a natural number.
  4. Classify 2/5 as rational or irrational.

Answers: 2/5; No, √9 = 3; −1; rational.

Long-answer / exam-style

Explain the difference between rational and irrational numbers with examples.
A rational number can be expressed as p/q with integers p and q and q ≠ 0, for example 3/4 or −2. An irrational number cannot be expressed in this form, for example √2. Rational decimals terminate or repeat; irrational decimals neither terminate nor repeat.

E. Application / case-based

A school map uses the entrance as (0,0). The library is at (3,4), and the playground is at (3,−2).

  1. In which quadrant is the library?
  2. In which quadrant is the playground?
  3. How far apart are the library and playground?
  4. Find the midpoint of the segment joining them.
Answers: Quadrant I; Quadrant IV; 6 units; (3,1).

F. Long / reasoning questions

1. Find the distance and midpoint between A(−2,1) and B(4,9).
Distance = √[(4+2)²+(9−1)²] = √(36+64) = 10 units. Midpoint = ((−2+4)/2, (1+9)/2) = (1,5).
2. Explain how coordinates can be used to check whether a triangle has a right angle.
Find the lengths of its three sides using the distance formula. If the square of the longest side equals the sum of the squares of the other two sides, the triangle is right-angled.

E. Application / case-based

A taxi charges a fixed booking fee of ₹30 and ₹12 per kilometre. Let x be the number of kilometres and C(x) the total cost.

  1. Write C(x) as a linear polynomial.
  2. Find the cost for 5 km.
  3. For what distance is the cost ₹90?
Answers: C(x)=12x+30; ₹90; 5 km.

F. Long-answer questions

Find the zero of p(x)=7x−21 and verify it.
7x−21=0 gives 7x=21, so x=3. Check: p(3)=21−21=0.
A rectangle has length (x+4) cm and width 3 cm. Write its perimeter as a polynomial and find it for x=5.
P=2[(x+4)+3]=2x+14. At x=5, P=10+14=24 cm.

F. Long-answer / reasoning

Show that 0.272727… is rational.
Let x=0.272727… Then 100x=27.272727… Subtracting, 99x=27, so x=27/99=3/11. Hence it is rational.
Explain why √2 is irrational.
A standard proof uses contradiction: assume √2=a/b in lowest terms. Squaring gives a²=2b², so a is even. Writing a=2k gives b²=2k², so b is also even. This contradicts that a/b was in lowest terms. Therefore √2 is irrational.
